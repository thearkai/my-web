About me

I'm KARUHANGA SYSON, professionally known as Syson Actin, a creative web developer and A-Level student from Rurehe, Mitooma District, Uganda.

I'm passionate about building modern, responsive web applications that solve real problems and create value. I enjoy learning new technologies, exploring creative ideas and turning them into digital solutions.

My work so far is front-end: semantic HTML, CSS that adapts properly to the screen it's on, and JavaScript that does something useful without dragging in a framework. I'm still early in this journey — which means I ask a lot of questions, test things properly, and would rather ship something honest than something impressive-looking that breaks.

my journey

How I got here.

A question, not a plan

It started with wondering how websites actually work underneath. Curiosity came first; the tutorials came after.

Learning the basics properly

HTML for structure, CSS for layout and responsive design, then JavaScript for behaviour — practised by rebuilding interfaces I liked until they made sense.

Building something of my own

That led to The Ark AI, an assistant for students and teachers, where the ideas finally have somewhere to go.

Next

Going deeper on JavaScript, writing about what I learn, and collaborating with other developers — including anyone reading this.

development philosophy

Three rules I try to code by.

Simple beats clever

If a piece of code needs a paragraph to explain it, it probably needs rewriting instead.

Design for the smallest screen first

If it works on a phone with a slow connection, it works everywhere else.

Be honest about what I don't know

Claiming more than I can do helps nobody — least of all the person trusting me with their project.
